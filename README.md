# 憲法のしくみ（kenpo-shikumi）

国の仕事の場面を見て、憲法がその仕事をだれに任せているか（国会・内閣・裁判所・天皇・国民）を当てる1日5問の学習ゲーム。正解したら「どんな働き？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/kenpo-shikumi/>

- 中身は e-Gov 法令検索「日本国憲法」の条文で確かめたことだけ（<https://laws.e-gov.go.jp/law/321CONSTITUTION>）。国の組み立てだけを扱い、意見の分かれる論点は扱いません。
- このゲームは法律の助言や、公式の情報の代わりではありません。正しい条文は e-Gov 法令検索で確かめてください。
- 場面はすべて練習のために作ったものです。記録は遊ぶ人のブラウザだけに残り、外へ送りません。
